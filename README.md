# Restaurant Management Application
## Overview
A comprehensive Android application for restaurant management with separate interfaces for staff and guests. Staff can manage menus and reservations, while guests can view menus and make reservations.

---


## Features
## Staff Features
  - **Menu Management:** Add, edit, and delete menu items with images

  - **Reservation Management:** View and cancel guest reservations

  - **Real-time Updates:** Auto-refresh after modifications

  - **Notifications:** Receive notifications for new reservations and cancellations

  - **Image Upload:** Add/change images for menu items

---


## Guest Features
  - **Menu Browsing:** View categorized menu items with images

  - **Reservation System:** Make table reservations with date/time selection

  - **Reservation Management:** Edit or cancel own reservations

  - **Notifications:** Receive confirmation and cancellation alerts

  - **User Settings:** Customize notification preferences

---


## Architecture
## Tech Stack
 - **Language:** Java

 - **Platform:** Android

 - **Database:** SQLite with Room-like helpers

 - **UI:** XML layouts with Material Design components

Storage: SharedPreferences for settings
